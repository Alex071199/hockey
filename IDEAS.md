# Идей бэклог (донаты, вовлечённость)

Статусы: `[x]` сделано, `[ ]` в плане.

## Монетизация и геймификация

- `[x]` **Дождь из логотипов + интенсивность от суммы** — длительность 6–30с, плотность и скорость растут с суммой.
- `[x]` **Тост поверх плеера** — имя, команда, сумма, сообщение донатора; видят все зрители матча (привязка по match_id, ttl = duration+10с).
- `[x]` **Сообщение и имя донатора из CloudTips** — поля comment/name на странице 00cb8ffe включены, идут confirm → БД → rain-event → тост.
- `[x]` **Объяснение оффера до доната** — блок «Что будет после доната» под кнопкой оплаты.
- `[ ]` **Апселл на голе** — триггер на live-счёт: при голе ненавязчивая плашка над плеером «ГОЛ! Поддержи команду → 200₽», закрытие через ~10с. Эмоциональный пик = лучшая конверсия.
- `[ ]` **Цель матча** — прогресс-бар под плеером («цель 10 000₽ → ...»), синхронизация с целями CloudTips.
- `[ ]` **Титулы болельщиков** — накопительные звания по сумме донатов: Новичок → Фанат → Легенда; бейдж в топе.
- `[ ]` **Донатор периода** — парад-плашка топ-3 по окончании периода прямо на трансляции.
- `[ ]` **Розыгрыш среди донатеров матча** — «каждый донат = билет», нужны призы/спонсор.
- `[ ]` **Эксклюзив ≥1000₽** — имя донатора на баннере матча до конца трансляции.
- `[x]` **Гейт перед плеером** — при первом открытии трансляции плеер не запускается, поверх оверлей «Поддержи сервис» + 2 кнопки: **«Поддержать»** → выбор команды/суммы и модалка CloudTips, **«Смотреть»** → стрим стартует. Стрим не грузится до клика (StreamPlayer не маунтится). Выбор «Смотреть» запоминается в localStorage на сутки (`hockey_gate_seen_at`); успешный донат тоже закрывает гейт. Компонент `PlayerGate.tsx`.

## Командный захват экрана (донат >1000₽)

- `[ ]` Не буквальная смена фона (проблема читаемости: яркие клубные цвета убьют контраст), а **смягчённая форма**:
  - цветное свечение по краям экрана + огромный полупрозрачный логотип команды-донатора на фоне;
  - для крупных сумм (1000+₽) — **до конца матча**, не 30 сек (ощущение владения, а не мигания);
  - cooldown + затемнение контента.
- Метафора: захват территории → усиливает «Соревнование болельщиков».

## Чат внутри трансляции

- `[ ]` Ступенчато, чат раньше времени не делать:
  1. **Реакции-эмодзи** (ГОЛ 🔥 / 👎 судья) — почти без модерации, ощущение толпы уже при 10 зрителях.
  2. **Полноценный чат** — когда вырастет аудитория (порог живости ~30 одновременно).
  3. **Связка с донатами**: донат ≥200₽ → подсвеченное сообщение в чате, сообщение за N₽, закреп топ-донаторов.
- Модерация: **вход через Telegram** (бот уже есть) — telegram_id, rate limit 5–10с, фильтр слов, жалобы, скрытие чата.
- Инфраструктура: WebSocket-менеджер уже есть (`backend/app/ws.py`), чат привязан к match_id.

## Смотреть ТВ (страница телеканалов)

- `[ ]` Кнопка **«Смотреть ТВ»** в меню (`Header.tsx`, navLinks — десктоп + мобильное) → страница `/tv`.
- Контент: плейлисты телеканалов **KHL** и **KHL PRIME** + ссылка на **NHL Network** — смотреть, когда нет прямых эфиров.
- Реализация: список каналов слева/сверху + плеер (`HlsVideo` уже умеет m3u8); чужие плейлисты — через существующие `/api/proxy/stream` и `/api/proxy/hls-proxy` (CORS).
- Ссылки на каналы хранить на бэке (JSON/конфиг) — добавление канала без пересборки сайта.
- От юзера нужны: сами плейлисты/ссылки (формат m3u или прямые m3u8) и ссылка NHL Network; вопрос — показывать список каналов с выбором или один открытый плеер по умолчанию.

## Зафиксировано из обсуждений

- DonatePay отклонён (9–10% комиссия, нет вебхуков/создания платежей).
- CloudTips: iframe разрешён, postMessage success = `{transactionId, identifier}` + (при включённых полях) name/comment; вебхука нет — confirm client-side с дедупом по tx_id (риск накрутки принят, защита: валидация + дедуп).
- Лимит страницы CloudTips 00cb8ffe: 49–5000₽, пресеты до 3000.
- Fullscreen: дождь не виден (ограничение Fullscreen API) — оставлено как есть осознанно.
- Модалка доната закрывается через 3.5с после успеха — дождь при суммах ≤200₽ донатор почти не видит (под модалкой z-70).
